In production, voice becomes text via Amazon Transcribe and Comprehend, photos are read by Rekognition and Textract, forecasts run on Prophet and scikit-learn, and Amazon Polly speaks the answer over WhatsApp. This prototype swaps those for the browser's own free speech APIs and a local version of the same scoring logic, so the recommendation math is real; only the AWS calls are stood in for.
